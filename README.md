# EjerciciosReactJs

Relación de ejercicios sencillos en **ReactJS** (basados en ejercicios ya realizados en JavaScript) realizados para su entrega y práctica.  
El objetivo de este repositorio es **practicar todo lo aprendido** con pequeños ejercicios sencillos, cada uno entregable, para afianzar conceptos.

## 🚀 Tecnologías

- React (^19.1.1)  
- Vite como herramienta de bundling/arranque rápido  
- Tailwind CSS para estilos  
- ESLint para linting  
- HTML5 / CSS3 / JavaScript (ES6+)  

## 📁 Estructura del proyecto

```
EjerciciosReactJs/
├── public/                # Archivos estáticos públicos
├── src/                   # Código fuente de los ejercicios
├── .gitignore             # Archivos y carpetas ignorados por Git
├── eslint.config.js       # Configuración de ESLint
├── tailwind.config.js     # Configuración de Tailwind CSS
├── vite.config.js         # Configuración de Vite
├── package.json           # Metadatos y dependencias del proyecto
└── README.md              # Este archivo
```

## ✅ ¿Qué encontrarás?

- Una colección de ejercicios pequeños, con distinto nivel de complejidad, para practicar React.  
- Ejercicios basados en lo ya trabajado en JavaScript, adaptados a React: por ejemplo uso de componentes, props, estado, hooks, manejo de listas, condicionales, etc.  
- Cada ejercicio pretende ser **entregable**: algo que puedas subir o compartir como mini‐proyecto.

## 🎯 Objetivos de aprendizaje

Al trabajar con este repositorio, podrás:

- Repasar los fundamentos de React: componentes, JSX, props, estado, hooks (`useState`, `useEffect`, etc.).  
- Adaptar ejercicios realizados en JavaScript puro al ecosistema React.  
- Usar Vite para crear un entorno ligero de desarrollo‑rápido.  
- Aplicar estilos usando Tailwind CSS para acelerar la maquetación.  
- Mantener un código limpio y consistente gracias a ESLint.  

## 📋 Cómo usar

1. Clona el repositorio:

   ```bash
   git clone https://github.com/JCMeloza/EjerciciosReactJs.git
   ```

2. Entra en la carpeta del proyecto:

   ```bash
   cd EjerciciosReactJs
   ```

3. Instala las dependencias:

   ```bash
   npm install
   # o bien, si usas yarn:
   # yarn
   ```

4. Arranca el entorno de desarrollo:

   ```bash
   npm run dev
   ```

   Esto levantará el proyecto en un servidor local (normalmente en `http://localhost:5173` o similar).

5. Abre tu navegador y navega hasta la URL indicada, selecciona un ejercicio del directorio `src` y empieza a practicar.

## 🧠 Buenas prácticas

- Lee bien el enunciado del ejercicio antes de comenzar.  
- Crea un componente para cada ejercicio o una carpeta individual por ejercicio para mayor claridad.  
- Usa nombres de variables y funciones descriptivos.  
- Mantén los estilos lo más simples y reutilizables posible.  
- Cuando completes un ejercicio, comenta qué aprendiste o qué dificultad tuviste para servicio de revisiones futuras.
